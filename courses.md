## Start here: the minimum viable track

If you only do six things, do these. ~60 hours total, all free, and they cover Phases 1–4.

| # | Course | Why this one |
| --- | --- | --- |
| 1 | [Neural Networks: Zero to Hero](https://karpathy.ai/zero-to-hero.html) — Karpathy | Nothing else demystifies LLMs this thoroughly. Build GPT from scratch. |
| 2 | [Generative AI with LLMs](https://www.coursera.org/learn/generative-ai-with-llms) — DeepLearning.AI + AWS | The best single structured overview of the LLM lifecycle. |
| 3 | [Anthropic Prompt Engineering Interactive Tutorial](https://github.com/anthropics/prompt-eng-interactive-tutorial) | Hands-on, in a notebook, from a frontier lab. |
| 4 | [Hugging Face LLM Course](https://huggingface.co/learn/llm-course) | The practical toolkit everyone in the field actually uses. |
| 5 | [Building and Evaluating Advanced RAG](https://www.deeplearning.ai/short-courses/building-evaluating-advanced-rag/) | RAG is the job. Evaluation is the differentiator. |
| 6 | [Hugging Face Agents Course](https://huggingface.co/learn/agents-course) | Agents, end to end, with real code. |

## Certifications

**Honest take:** certifications rarely get you hired for GenAI roles on their own — a deployed
project with an eval table does more. But they help if you're changing companies within a
cloud-centric org, need to pass an HR keyword filter, or want external deadlines for motivation.

Pick **at most one**, matching the cloud your target employers use.

| Certification | Provider | Cost | Notes |
| --- | --- | --- | --- |
| [AWS Certified AI Practitioner](https://aws.amazon.com/certification/certified-ai-practitioner/) | AWS | ~$100 | Foundational, broad, easy entry |
| [AWS Certified Machine Learning Engineer – Associate](https://aws.amazon.com/certification/certified-machine-learning-engineer-associate/) | AWS | ~$150 | More technical; Bedrock + SageMaker |
| [Azure AI Engineer Associate (AI-102)](https://learn.microsoft.com/certifications/azure-ai-engineer/) | Microsoft | ~$165 | Best if your shop is Microsoft/OpenAI |
| [Google Cloud Professional ML Engineer](https://cloud.google.com/learn/certification/machine-learning-engineer) | Google | ~$200 | Hardest of the cloud certs |
| [Databricks Generative AI Engineer Associate](https://www.databricks.com/learn/certification/generative-ai-engineer-associate) | Databricks | ~$200 | Strong signal in data-platform orgs |
| [NVIDIA-Certified Associate: Generative AI LLMs](https://www.nvidia.com/en-us/learn/certification/generative-ai-llm-associate/) | NVIDIA | ~$135 | Vendor-neutral-ish fundamentals |

## Staying current (ongoing, ~2 hrs/week)

Pick two or three. Following everything is a full-time job and a trap.

**Newsletters**
- [The Batch](https://www.deeplearning.ai/the-batch/) — DeepLearning.AI, weekly, balanced
- [Import AI](https://importai.substack.com/) — Jack Clark, policy + research
- [Latent Space](https://www.latent.space/) — the AI Engineer newsletter/podcast
- [Ahead of AI](https://magazine.sebastianraschka.com/) — Sebastian Raschka, technical depth

**Engineering blogs**
- [Anthropic Engineering](https://www.anthropic.com/engineering)
- [Lilian Weng's blog](https://lilianweng.github.io/)
- [Chip Huyen](https://huyenchip.com/blog/)
- [Simon Willison](https://simonwillison.net/) — the best running commentary on practical LLM use
- [Eugene Yan](https://eugeneyan.com/)

**Communities**
- Hugging Face forums & Discord
- r/LocalLLaMA — the pulse of open-weight models
- The AI Engineer conference talks (free on YouTube)
